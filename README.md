# منصة «بلّغ» — Ballegh

> منصة بلاغات جغرافية لمحافظة الفيوم تربط شكوى المواطن بنطاق الوحدة المحلية المسؤولة، وتحوّل سرعة الاستجابة وجودة الحل إلى **مؤشرات أداء** يتابعها المحافظ وغرفة العمليات لحظياً.
>
> اسم المنصة المعتمد: **«بلّغ»** (Ballegh). منصة بلاغات محافظة الفيوم.

| | |
|---|---|
| **الجهة المستفيدة** | ديوان عام محافظة الفيوم |
| **النطاق الجغرافي** | كل مراكز المحافظة: القرى والمدن والأحياء |
| **الحالة** | مرحلة التوصيف والتحضير للعرض على المحافظ (عرض تقديمي + نموذج تجريبي) |

---

## المشكلة
- شكاوى القرى والمدن بتظهر على السوشيال ميديا قبل ما توصل للجهة المسؤولة، ومفيش مصدر موحد يقيس أداء الوحدات المحلية.
- المحافظة مش بتعرف بشكل لحظي: فين المشاكل؟ ونوعها إيه؟ ومين اتأخر في حلها؟
- محاسبة رؤساء الوحدات المحلية بتعتمد على بلاغات متفرقة، من غير سجل موثّق يصلح كمستند.

## الحل في سطرين
المواطن يصوّر المشكلة من موبايله، والسيستم ياخد الإحداثيات ويحدد **الوحدة المحلية المختصة تلقائياً** ويبعتلها البلاغ. الوحدة تشتغل عليه وتقفله بصورة من نفس المكان، وغرفة العمليات تتابع كل ده على الخريطة ومؤشرات الأداء.

## المستخدمون
| الدور | الأداة | يشوف إيه |
|---|---|---|
| المواطن | تطبيق موبايل | بلاغاته وحالتها والرد عليها |
| موظف الوحدة المحلية | تطبيق موبايل + ويب | البلاغات المسندة له |
| رئيس الوحدة المحلية | تطبيق موبايل + ويب | بلاغات نطاق وحدته فقط، وترتيب وحدته |
| رئيس المركز / المدينة | ويب | الوحدات التابعة لمركزه |
| غرفة العمليات (مشرف، مراجع) | لوحة ويب | المحافظة كلها، والإعدادات |
| المحافظ | لوحة موبايل + ويب | المؤشرات والخريطة والتقارير |

## الوحدات الرئيسية (Modules)
1. **تطبيق المواطن:** تسجيل، تقديم بلاغ (صور / فيديو / وصف صوتي)، يشتغل بدون إنترنت، سجل البلاغات، تقييم الحل.
2. **محرك التوجيه الجغرافي:** يحدد الوحدة المختصة من الإحداثيات (Point-in-Polygon)، ويكتشف التكرار ويجمّعه.
3. **محرك الأولويات ومدد الحل (SLA):** أولوية حسب النوع والتكرار والموسم، وتصعيد تلقائي عند التأخير.
4. **بوابة الوحدة المحلية:** استلام وتوزيع وحل البلاغات، ونموذج تقرير الحل.
5. **غرفة العمليات:** خريطة لحظية، خريطة حرارية، مراجعة وعينات، وإعدادات النظام.
6. **لوحة المحافظ:** مؤشرات مختصرة، إنذارات، وتقارير PDF.
7. **سجل التدقيق (Audit Log):** كل إجراء مسجل ولا يمكن تعديله، ويصلح كمستند رسمي.
